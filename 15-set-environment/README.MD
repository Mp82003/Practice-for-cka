# Q15 – Set Environment Variables in a Pod

## Objective

Create a Pod named `env-demo` using `busybox:latest` and configure environment variables inside its container.

## Requirements

- Use a YAML manifest.
- Set `APP_NAME=NovaPay`.
- Set `APP_ENV=development`.
- Define environment variables using the `env` field.
- Verify the environment variables inside the container.

## 1. YAML Manifest

File: `env-demo.yaml`

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: env-demo
spec:
  containers:
    - name: env-demo
      image: busybox:latest
      command: ["sh", "-c"]
      args: ["echo $APP_NAME; echo $APP_ENV; sleep 300"]
      env:
        - name: APP_NAME
          value: "NovaPay"
        - name: APP_ENV
          value: "development"
```

## 2. Apply the Manifest

```bash
kubectl apply -f env-demo.yaml
```

**Output:**

```text
pod/env-demo created
```

## 3. Check Pod Status

```bash
kubectl get pod env-demo
```

Expected status: `Running`

## 4. Verify Environment Variables Through Logs

```bash
kubectl logs env-demo
```

Expected output:

```text
NovaPay
development
```

## 5. Inspect Environment Variables Directly

```bash
kubectl exec env-demo -- printenv APP_NAME
kubectl exec env-demo -- printenv APP_ENV
```

Expected output:

```text
NovaPay
development
```

## 6. Key Concepts Learned

### Environment Variables

Environment variables provide configuration values to applications running inside containers.

### env

The `env` field defines environment variables for a container.

### name

Specifies the environment variable name.

### value

Specifies the value assigned to the environment variable.

### kubectl exec

Executes a command inside a running container.

### kubectl logs

Displays the output generated by a container.
