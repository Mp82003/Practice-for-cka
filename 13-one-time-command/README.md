# Q13 – Run a One-Time Command in a Pod

## Objective

Create a Pod named `date-check` using `busybox:latest` that prints the current date and then exits.

## Requirements

- Use a declarative YAML manifest.
- Set the container command to execute the `date` command.
- Set `restartPolicy: Never`.
- Apply the manifest and wait for completion.
- Read container logs and verify the date output.

## 1. YAML Manifest

File: `date-check-pod.yaml`

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: date-check
spec:
  restartPolicy: Never
  containers:
    - name: date-check
      image: busybox:latest
      command: ["sh", "-c", "date"]
```

## 2. Apply the Manifest

```bash
kubectl apply -f date-check-pod.yaml
```

## 3. Inspect Pod Status

```bash
kubectl get pod date-check -w
```

Expected final status:

```text
NAME         READY   STATUS      RESTARTS
date-check   0/1     Completed   0
```

## 4. Read Container Logs

```bash
kubectl logs date-check
```

**Observed output:**

```text
Thu Nov 19 16:00:01 UTC 2026
```

The date command successfully printed the current date and time before the container exited.

## 5. Key Concepts Learned

### One-Time Command

A one-time command executes inside a container and exits after completing its task.

### command

The `command` field specifies the executable command that runs when the container starts.

### restartPolicy: Never

Prevents Kubernetes from restarting the container after it exits.

### kubectl logs

Displays the output generated by a container.
